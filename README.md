# Vidoo Android MVP

Kotlin + Jetpack Compose starter. Open this folder in Android Studio (JDK 17) and sync Gradle.

Implemented: video prompt editor and duration selector.
Pending: secure backend, fal.ai integration, job polling, video player, downloads, payments.

Never embed fal.ai API keys in the Android APK. Add a backend before enabling generation.

This is a source starter, not yet a verified APK build. Gradle wrapper can be generated using an installed Gradle distribution or Android Studio.
